# Bleu Blanc Cloud — site publié

Ce dépôt contient uniquement le site statique généré de
[Bleu Blanc Cloud](https://bleublanccloud.fr), publié automatiquement.
Le code source est ici : <https://github.com/Berachem/bleu-blanc-cloud>.

## Demander l'analyse d'un site

Ouvrez un ticket avec le modèle **« Analyser mon site »** (onglet *Tickets* → *Nouveau ticket*).
Un robot le traite en général en moins d'une heure et répond dans le ticket.
Règles : <https://bleublanccloud.fr/methodologie/>.

Pour une correction ou une demande de retrait : <https://bleublanccloud.fr/retrait/>.
